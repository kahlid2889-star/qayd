# قيد — نسخة المشروع الكاملة

هذه هي ملفات المشروع الأصلية: لعبة البلوت **قيد** (واجهة عربية، حساب، ديوانية، أصدقاء، ورتب). الأرشيف يكفي لإعادة بناء المشروع وتشغيله على جهازك من غير المنصة.

## ماذا داخل النسخة

- الكود: `src/` و`public/qayd.html` (الطاولة) و`public/qayd-net.js` (الديوانية).
- الواجهة والصور: `public/` بما فيها شعار المشاركة، أيقونة الموقع، كرت الجوكر، ولافتة العرض.
- صور اللاعبين والورق والصوت مضمّنة داخل `public/qayd.html` (رسوم مدمجة ومحرّك صوت في المتصفح، وليست ملفات mp3 منفصلة).
- قاعدة البيانات: مخططاتها فقط في `migrations/` من `0001` إلى `0010` (الحساب، الغرف، الصكة، الخبرة، الأصدقاء، سجل الصكات والدعوات، إعدادات الجلسة، الإشعارات، التقييم، القطع). تُطبَّق تلقائيًا عند التشغيل.
- الإعدادات: `package.json` و`package-lock.json` (إصدارات المكتبات مثبتة) و`vite.config.ts` و`tsconfig.json` و`vercel.json` و`eslint.config.mjs` و`.prettierrc` و`.grok/` و`scripts/` و`server/` و`startup.sh`.

## ماذا لا يوجد هنا، ولماذا

| المستبعد | السبب |
|---|---|
| `node_modules/` | تُستعاد كما هي بالأمر `npm ci` من `package-lock.json`. حجمها حوالي ٤٠٤ ميجابايت وليست مصدرًا. |
| `.vercel/` | ناتج بناء يتجدد بالأمر `npm run build`. |
| `screenshots/` و`attachments/` | لقطات فحص ومرفقات شخصية. لا تُرفع إلى المستودع (مذكورة في `.gitignore`). |
| ملف قاعدة حي | القاعدة المحلية ذاكرة داخل العملية. لا يوجد ملف حسابات لتصديره. عند التشغيل تُنشأ قاعدة فارغة بنفس الجداول. |

لا تُحذف من هذه النسخة أي ميزة. الملفات أعلاه هي أصول المشروع.

## الخطوط

العرض العربي يعتمد على خطّي Tajawal وReem Kufi من Google Fonts، فيحتاج اتصالًا عند أول فتح. أُزيل طلب الملف الناقص `/fonts/kufi-900.woff2` من الصفحة.

للنقل إلى خادم تملكه اقرأ `TRANSFER.md`، وللتغييرات الأخيرة اقرأ `CHANGES.md`.

## التشغيل على جهازك

يلزم Node.js 22 أو أحدث، وnpm معه.

```bash
unzip qayd-backup.zip -d qayd
cd qayd
npm ci
npm run dev
```

ثم افتح `http://127.0.0.1:8080`.

لا تشغّل `startup.sh` على جهازك: هو لمشغّل المنصة ويفترض مجلدًا ثابتًا. أمر التشغيل الصحيح هو `npm run dev`.

من غير أي متغير بيئة تعمل اللعبة على قاعدة Postgres مضمّنة (PGLite). البيانات تبقى ما دام الخادم يعمل، وتُمسح عند إيقافه. هذا سلوك القاعدة المحلية، لا نقص في الملفات.

## الإبقاء على البيانات

1. أنشئ قاعدة Postgres فارغة.
2. ضع عنوانها في البيئة قبل البناء والتشغيل:

```bash
export DATABASE_URL="postgres://USER:PASSWORD@HOST:5432/qayd"
npm run db:migrate
npm run dev
```

`npm run db:migrate` يطبّق ملفات `migrations/` بالترتيب ويسجّل ما طُبّق في جدول `_migrations` حتى لا يُعاد.

الدخول بكلمة المرور مفعّل في الكود. الدخول عبر Google أو X يحتاج أسرار المنصة (`BETTER_AUTH_SECRET` و`BETTER_AUTH_URL` و`GROK_AUTH_*`) ولا تُنسخ مع المشروع حتى لا تُسرَّب مفاتيح.

## إعادة البناء والفحص

```bash
npm run typecheck
npm run lint
npm test            # اختبارات اللعبة: الحساب، القوانين، الخبرة، الأصدقاء، البريد
npm run build
```

`npm run test:platform` يشغّل اختبارات قالب منصة Grok. ١٣ منها تفشل هنا عن قصد، لأن قيد يفعّل الحسابات ويغيّر مكان الهجرات عمّا يفترضه القالب.

البناء ينتج نسخة النشر ويعيد تطبيق الهجرات إذا وُجد `DATABASE_URL`. من غيره تُتخطى هجرة Postgres لأن PGLite يطبّق المخطط عند الإقلاع.

## استعادة الأرشيف إذا انقسم

هذه النسخة ملف واحد. إن وصلتكم أجزاء مرقّمة `qayd-backup.z01` ثم `qayd-backup.zip` فاجمعوها بـ:

```bash
zip -s 0 qayd-backup.zip --out qayd-backup-full.zip
unzip qayd-backup-full.zip -d qayd
```

بعد فك الضغط يجب أن يوجد `package-lock.json` و`public/qayd.html` و`migrations/0005_qayd_friends.sql` و`src/lib/qayd/server.ts`. قائمة كل الملفات في `FILE-LIST.txt`.
